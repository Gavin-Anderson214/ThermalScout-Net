# Later: Two-level presentation plan

The goal is to first show a **tiny, understandable AI demo**, then reveal the full research project. This is a plan only; the separate presentation version is not built yet.

1. **Small demo (later):** a single clearly annotated Python file, a synthetic thermal image, and a displayed human/animal detection example. Explicitly label all data as synthetic.
2. **Full research implementation:** show the organized `thermalscout/` modules and explain the complete real-image pipeline.
3. **Quantitative results:** show only recorded and reproducible real-data precision, recall, mAP, and speed. Compare scratch training, transfer learning, and a YOLO baseline after those runs have been completed.
4. **IEEE presentation:** explain the project problem, objective, methodology, experimental controls, limitations, and future work.

Never present a synthetic prediction-confidence percentage as a measured real-world accuracy score.
